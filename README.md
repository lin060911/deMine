# 反向扫雷 · 模块化重构版 v1.1.0

原 `game.js`（4793 行单文件）+ `audio.js` 已拆分为 `js/` 下 16 个按职责划分的模块，
同时修复了 4 个隐患。**游戏规则、UI、数值、题库码格式全部未改动。**

## 一、怎么跑

直接双击 `index.html` 即可（全部是普通 `<script>`，不需要本地服务器、不需要打包、不需要 node）。

> ⚠️ 原工程引用的 `image/bomb.png`（网页图标）不在本次交付的文件里，
> 请把你原工程里的 `image/` 目录整个拷到本文件夹下，图标就能正常显示；
> 不拷也不影响任何功能，只是标签页图标会缺失。

## 三、四项修复

### 1. AudioContext 泄漏 ✅
- 原来 `AudioFX`、`RetroBGM`、`playAchievementSound()` 各自 `new AudioContext()`，
  且成就音那个用完从不 `close()` —— 浏览器同时允许的 AudioContext 有上限（Chrome 约 6 个），
  成就密集解锁时会静默失效，而空的 `catch(e){}` 又把错误吞掉，表现为"声音突然没了"。
- 现在**全局只有一个 AudioContext**，SFX 走 `sfxBus`（上限 0.35）、BGM 走 `bgmBus`（上限 0.13），
  混响只挂在音效总线上。音量系数集中成 `SFX_MAX` / `BGM_MAX` 两个常量。

### 2. 存档加固 ✅（纯前端，无需后端）
- **单点封装**：36 处裸 `localStorage` 调用全部改走 `Store`，任何一次抛错都不再让脚本停摆。
- **内存降级**：Safari 隐私模式 / `QuotaExceededError` 时自动降级到内存，本局照常能玩。
- **双份写入**：成绩、胜场、系列解锁、成就每次写入前把上一份好数据备份到 `<key>__bak`，
  读取时主档损坏自动回退备份档，并标记 `Store.tampered`。
- **结构校验**：读出来的值必须是合法对象才采用，否则回退默认值（以前 `JSON.parse` 出一个数字也会往下传）。
- **schema 版本**：`rmSchemaVersion` + 迁移钩子，以后改结构不会炸老玩家。
- **导出/导入**：设置侧边栏新增「💾 存档管理」，一键导出 JSON 文件 / 导入（可覆盖或合并）/ 清空。
  换设备、清浏览器缓存前记得导出一份。

### 3. 差量渲染 + 只播最新落雷动画 ✅
- 原来每放/删一颗雷就 `innerHTML = ""` 重建整盘：20×20 要新建 400 个 div + 重绑 400 次事件，
  而且**所有已放置的雷都会重播一遍落雷动画**，后期满屏乱抖。
- 现在网格只建一次，之后只更新变化的格子；点击/右键改为事件委托（一次绑定，不再反复绑）。
- 落雷动画：只有「本次新出现」的那一颗会播放 `cellMineDrop`；全量重建时一律不播。
- **六道保险**（针对"手忙脚乱或暴力测试下显示与状态不一致"）：
  1. 状态体检：`G.tar` / `G.p` 行列数与 `SR/SC` 不符 → 不画，记日志；
  2. 网格体检：逐格校验节点数、父子关系、`data-r/data-c`，任何一格对不上就整块重建；
  3. 尺寸变化：窗口缩放导致格子边长变化时自动重新应用棋盘度量；
  4. 过程兜底：差量更新中途抛异常 → 自动回退全量重建再来一遍；
  5. 结果不变量：画完比对 DOM 上的雷数与 `G.placed` 数量，不等就强制重建；
  6. 最终兜底：连全量重建都失败，用最朴素的 `legacyRender` 画一遍，保证看得见棋盘而不是白屏。
- 未知雷种会被识别并拒绝渲染（不会显示成错的雷），只记日志。
- 教学模式棋盘用 `.rm-diff` 标记隔离，保留它原有的落雷动画，不受影响。

### 4. 计时器 ✅
- 基准从 `Date.now()` 换成 `performance.now()`（单调时钟）：改系统时间不影响读数。
- **不加暂停**：切后台 / 息屏照常累加，回到页面立刻刷新显示（`visibilitychange` + `pageshow`）。
- **静默反作弊**：
  - 真实耗时存在闭包变量里，改全局 `ct` / `st` 改不动最终成绩；
  - 墙钟与单调钟互校，取更长的那个 —— 时间只会被拉长，不可能用来刷快（设备休眠也计入）；
  - 发现系统时间被回拨时打 `RM.timer.suspicious()` 标记，不弹窗不打扰；
  - 成绩写入走 `RM.timer.ms()`，只增不减。
