## 四项修复

### 1. AudioContext 泄漏 ✅
### 2. 存档加固 ✅（纯前端，无需后端）
- **内存降级**：Safari 隐私模式 / `QuotaExceededError` 时自动降级到内存，本局照常能玩
- **双份写入**：成绩、胜场、系列解锁、成就每次写入前把上一份好数据备份到 `<key>__bak`，
  读取时主档损坏自动回退备份档，并标记 `Store.tampered`
- **结构校验**：读出来的值必须是合法对象才采用，否则回退默认值（以前 `JSON.parse` 出一个数字也会往下传）
- **schema 版本**：`rmSchemaVersion` + 迁移钩子，以后改结构不会炸老玩家
- **导出/导入**：设置侧边栏新增「💾 存档管理」，一键导出 JSON 文件 / 导入（可覆盖或合并）/ 清空
  换设备、清浏览器缓存前记得导出一份
### 3. 差量渲染 + 只播最新落雷动画 ✅
### 4. 计时器 ✅
- 基准从 `Date.now()` 换成 `performance.now()`（单调时钟）：改系统时间不影响读数。
- **静默反作弊**：
  - 真实耗时存在闭包变量里，改全局 `ct` / `st` 改不动最终成绩；
  - 墙钟与单调钟互校，取更长的那个 —— 时间只会被拉长，不可能用来刷快（设备休眠也计入）；
  - 发现系统时间被回拨时打 `RM.timer.suspicious()` 标记，不弹窗不打扰；
  - 成绩写入走 `RM.timer.ms()`，只增不减
