📖 规则信息

💡 玩法：反向扫雷（布雷）

  • 目标：
    在棋盘上放置规定数量的地雷（普通雷 + 特殊雷），使得棋盘上每个格子显示的数字，恰好等于它周围（或特定规则下）所有地雷对它的总影响值
  • 操作：
    点选：点击选中地雷，再点击棋盘放置
    拖拽：将地雷拖到棋盘上松手
    删除：右键点击（手机端长按地雷）
  • 胜利条件：
    所有地雷放完，且棋盘数字与地雷影响匹配（棋盘上都是🟩）

🧩 地块状态解读

游戏会根据你当前的布雷情况，实时用颜色提示每个格子：

  • 🟩 合适：该格子的当前影响值 [等于] 显示数字（正确）
  • 🟨 偏低：该格子的当前影响值 [小于] 显示数字（还需在周围加雷）
  • 🟥 偏高：该格子的当前影响值 [大于] 显示数字（还需减少影响值）

🔓 系列开关机制

  • 基础系列始终开启，未解锁的系列显示为灰色
  • 其他系列需通过对应挑战（5关）后解锁
  • 解锁后可随时调整开关，无需切换模式
  • 简单/中等：无系列门槛，可直接开始✅
  • 困难：需开启≥3个系列开关
  • 地狱👿：需开启至少5个（共6个）系列开关
  • 脑王🤯：地狱通关≥10次 + 开启至少5个（共6个）系列开关
  • 🔧自由模式：可自定义参数，不记录成绩

🪚 硬核模式

  • 在「🕹️难度 → 游戏选择 → 🎲 玩法」里开启
  • 隐藏 🟩🟨🟥 三态配色，
    数字格变成灰白色、数值为 0 的空地变成蓝色，颜色不再随局面变化
  • 开启期间「🔺实时影响」与「👀效果预览」被锁定
  • 状态行显示「💣 已放置雷数：n/m」；硬核局还显示「🧩 地块准确数：x/x」

🧱 俄罗斯方块模式

  • 在「🕹️难度 → 游戏选择 → 🎲 玩法」里开启
  • 地雷槽换成 I/O/J/L/S/Z/T 七种四格骨牌，槽内可旋转；
  • 每块骨牌覆盖的 4 格各 +1；自身格不可叠放，影响值可叠加
  • 双击棋盘上已放置的骨牌可绕锚点顺时针旋转；右键 / 长按删除整块
  • 仅预设难度 / 自由模式生效，成绩单独记在「📝记录 → 成绩 → 俄罗斯方块」标签
